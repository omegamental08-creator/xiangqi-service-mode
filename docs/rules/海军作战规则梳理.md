# 海军作战规则梳理

> 来源：[[象棋兵营模式完整规则]] §6.1–6.4、§10、§12.4、§13.3、§25；图谱节点 [[07-海战与舰船]]。
> 状态标注：**【正式】** = 已并入完整规则的正式条款；**【待确认】** = 规则内明确留白。
> 本文只归拢与交叉引用，不改原规则；§10 全章为 2.0 及以上启用。

## 1. 版本定位

| 版本 | 海战状态 |
| --- | --- |
| 0.0 / 1.0 | 纯陆战，无水性单位 |
| 2.0 及以上 | 启用海战、水性单位与舰船运输 |
| 3.0 / 4.0 | 海战 + 空战叠加（战机可攻击水面舰船，见 §6） |

---

## 2. 谁能下水、谁算船（§6.2、§10.1）【正式】

| 单位 | 水上身份 | 说明 |
| --- | --- | --- |
| 将 | **始终**水上载体 | 容量 1 |
| 兵 | **始终**水上载体 | 无需激活、无需搭载乘员 |
| 兵营 | **始终**水上载体 | 空载也可入水 |
| 象、士 | **按激活与装载状态**取得运输载体资格 | 未取得资格时不能当船用 |
| 防（防空炮） | 水性单位，**始终视为舰船** | **有水上身份 ≠ 能攻击** |
| 车、马、炮 | 陆性单位 | 需桥梁、被船运输或渡劫跨越水域 |

三条容易混的边界：

1. **「能被装载」≠「能装载别人」**：车可以上船，但车自己不是船。
2. **运输船资格 ≠ 空军起降平台资格**：战机平台另见 §12.4（须象 / 士 / 兵，且已激活空载）。
3. **有水上身份 ≠ 有海战攻击力**：防无普通吃子、无接舷、无舰炮。

## 3. 装载（§10.2）【正式】

**条件（全部满足）**

- 载体与货物同方，或属于允许共享运输关系的盟友
- 货物与载体**相邻**
- 载体有**剩余容量**
- 货物本回合**未被其他行动占用**
- **象在桥上时不能装载**

**容量**

| 载体 | 容量 |
| --- | --- |
| 将 | 1 |
| 象 | 4 |
| 士 | 1 |
| 兵营 | 1 |
| 防 | 按其自身容量规则（**数值未定义 → 待确认**） |

**装载后**

- 货物从棋盘移入载体内部，**不再占独立棋盘位置**
- 装载属**布阵行为**
- 货物本回合视为**已行动**，不能再次独立移动

---

## 4. 卸载（§10.3）【正式】

- 只能卸到载体**上下左右相邻**位置
- 目标必须是**空的陆地点**
- 卸载后棋子恢复独立棋盘位置
- 卸载后该棋子本回合**视为已行动**
- 卸载属**布阵行为**

---

## 5. 舰内换序（§10.4）【正式】

- 可在舰船详情中调换货物**上下顺序**
- 顺序决定舰炮攻击时**谁是最上层炮手**
- 换序属**布阵操作**，货物不会因换序自动移动

---

## 6. 接舷战（§10.5）【正式】

- 有接舷资格的舰船可消灭**上下左右相邻**目标，并**占据目标原位置**
- 属**布阵中的移动行为**，不占攻击回合类别
- 目标是**有乘员的船**时，目标船与全部乘员**一起被消灭**
- 对**盟友**接舷＝主动背盟：触发强制解盟、**质子不返还**，无需先协商解盟
- 同一相邻目标也可能满足舰炮条件 → **由玩家选择行为**，按所选行为的回合类型结算，不能强制一律接舷

---

## 7. 舰炮（§10.6）【正式】

- 船装载有**可攻击棋子**时，可用**最上层货物**执行舰炮
- **相邻目标也能用舰炮**，前提是最上层炮手按自身攻击规则能命中
- 若最上层是**炮**：必须满足**隔 1 个棋子**的炮击条件
- 命中后**最上层货物被消耗**并进淘汰区；**船体留在原位**
- 舰炮属**攻击回合**
- **兵营**没有攻击力，不能当炮手；**防空炮、直升机**不能执行普通舰炮攻击

> 舰炮 vs 接舷的分界：**炮手消耗、船不动**＝舰炮；**船移到目标位置**＝接舷。

---

## 8. 击毁舰船（§10.7）【正式】

舰船被普通攻击、接舷战或空战击毁时：

- 船体进淘汰区
- **全部货物同时进淘汰区**
- 货物**分别记到各自所属玩家的淘汰区**
- 兵营货物仍然**不回补**到战备区

---

## 9. 地形与通行（§6.1–6.3）【正式】

- **陆地点判定**：棋子落在交叉点，周围四格中**至少一格是陆地** → 该点按陆地点处理
- 陆性单位普通生产落点须为陆地点；**水性单位不受此限制**
- **海区**：2.0+ 启用；车马炮等陆性单位通常需桥梁、被船运输或渡劫跨水
- **河流区**：属水域；普通陆性单位不能直接落在完全水域；水陆交界按**是否接触陆地**判断
- 士跳子、桥梁、渡劫各有特殊通行条款

---

## 10. 与空战的交叉

- **战机可攻击水面舰船**，命中按整船损失处理（§13.3 → §10.7）
- **防空炮「防」**同时是舰船与 3×3 禁飞区载体：水上机动仍会产生敌方战机禁飞区（§13.1）
- **直升机「直」**不能舰炮、不能吃子；它的四邻是禁飞＋杀伤区（§13.2）
- **运输资格 ≠ 起降平台资格**：战机只能从象 / 士 / 兵平台起降，船上不行（§12.4）
- 同点「可攻击目标 + 防空区」的结算优先级仍是 **Q5 待确认**，禁止默认先炸防空

## 12. 速查表

| 问题 | 答案 |
| --- | --- |
| 谁能当船？ | 将、兵、兵营（始终）；象、士（激活＋装载状态）；防（视为舰船）；车马炮不行 |
| 船怎么走？ | 普通移动上下左右 1 格 |
| 装货要相邻吗？ | 要；且载体有剩余容量、货物本回合未行动 |
| 象什么时候不能装货？ | 在桥上时 |
| 卸货卸到哪？ | 相邻的**空陆地点** |
| 舰炮打相邻目标可以吗？ | 可以，只要最上层炮手能命中 |
| 舰炮打完炮手去哪？ | 进淘汰区；船留在原位 |
| 炮要隔子吗？ | 最上层是炮时，必须隔 1 个棋子 |
| 兵营能开炮吗？ | 不能，无攻击力 |
| 防空炮/直升机能开炮吗？ | 不能 |
| 船被打沉货物怎么办？ | 一起进淘汰区，按各自所属玩家分别记录；兵营货物不回补 |
| 打盟友的船？ | 主动背盟，强制解盟，质子不返还 |
| 战机能不能炸船？ | 能，整船损失 |
| 船能不能当战机平台？ | 不能，只有象 / 士 / 兵平台可以 |
