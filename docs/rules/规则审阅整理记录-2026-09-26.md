## 原文未批注但需要消除的冲突

- 遭遇战“其他普通棋子不进入准备区”与实际保留库存、兵营生产相冲突，改为“初始不上场，剩余库存留准备区”。
- “兵作为船不需激活”与“战机要求激活平台”分开表述；运输资格不自动放宽空军平台资格。
- 库存、轮换、生产和胜负章节统一引用狂热生产分支，避免一处允许、一处一律禁止。
- 随机地图保留后续新增的大小参数；百分比是基础半径倍率，不称实际面积百分比。
- 0.0 不再以模式名称为证据宣称代码已完成将死、困毙判定。
- “远程攻击”不再把场上炮写成不移位，舰炮保留船本体不动。

## 文档与代码尚有差异

以下为已读代码与修订规则的差异线索，未在本次更改实现，也未逐项进行运行验证。

| 规则 | 当前代码线索／后续核对点 |
|---|---|
| 兵始终水性运输 | `isShipUnit`、`getShipAt`、`canReach` 仍依赖装载／激活等状态 |
| 任意绑定将席可建设、水性可在水点生产 | `playerJiangInJiangXi` 限己方；`canPlaceBingAt`、`canProduceAt` 仍有陆地点限制 |
| 响应允许全部四类及外交 | `enqueueCommand` 白名单和 `showDiplomacyModal` 仍有响应限制 |
| 普通炮吃子后移位 | `paoShot` 仍调用远程不移位结算 |
| 相邻舰炮 | `canShipCannonHit` 排除相邻点，点击入口优先接舷 |
| 直飞越棋子 | `canReach` 的直分支仍检查中间棋子 |
| 最多六步航线、炸船 | 航线入口等待六点；`resolvePlannedFlight` 沿途攻击排除水性单位 |
| 寄生生产需兵营、轮换回收附着 | 生产和轮换入口需补一致校验 |
| 狂热生产方案 | 现有狂热入口清空准备区并停止轮换 |
| 将帅照面 | 已有水域与桥连通辅助逻辑，需与新版规则分别核对 |
| 铁幕覆盖舰炮等所有攻击 | 普通攻击调用寄生防御，舰炮、接舷、航线走专用消灭流程，效果覆盖不一致 |
| 载体毁坏与乘员损失 | 不同攻击入口的整船销毁调用并不一致，需要统一 |
