## 如何在 Obsidian 查看

1. 打开本笔记。
2. 右键笔记标签或打开命令面板，执行“打开局部关系图”。
3. 将深度设置为 2 或 3，可以同时看到核心规则和扩展规则。
4. 点击节点即可跳转到对应规则笔记。
