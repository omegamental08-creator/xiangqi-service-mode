- 对原始页面运行既有 Playwright 浏览器回归，覆盖菜单、随机地图生成与保存、布子、分层威胁链、威胁消失、棋子详情、情报面板、缩放等已有场景。
- 新专项在独立无头 Chrome 浏览器上下文中运行，每项重新设置固定局面；通过内存响应注入只读出内部状态和原有函数的测试入口，不将测试入口写入游戏文件，不替换游戏判定函数。
- 专项混合使用公开动作 API、真实点击处理函数、内部规则函数。内部函数通过仅代表该判定或结算路径通过，不等于全部可见按钮操作已验收。
- R07 使用公开动作提交；R12、R16、R24 使用原有棋盘点击处理；R14 单独测试响应命令白名单，不代替每类行动全部先决条件的端到端验证。
- 使用独立浏览器存储，不修改用户日常浏览器的地图和存档。本轮观察到的浏览器页面未捕获未处理 JavaScript 异常。
- 不宣称遍历全部棋盘、全部版本组合、全部胜负条件或完成真实跨设备联机测试。

## 已通过的重点

- 1.0 空载兵不能进入完全水域；陆地建设的空位和越界限制。
- 非相邻舰炮消耗顶层炮手，船体不移动。
- 坠机冲撞落点友军但不伤邻格。
- 铁幕与渡劫两种先后顺序都抵消，宿主保留；普通攻击触发铁幕防御。
- 将帅照面有水域阻断，补桥可恢复；士跳子坐标例子及敌方阻挡。
- 第二个象激活与否均可按桥端点过桥；桥规划可延伸至地图有效边界。这里只验证判定/规划，不宣称过桥全部界面操作通过。
- 车可被装载但不是舰船；马解除部署扣一步。
- 清除普通移动命令恢复位置和步数；布阵不能混入攻击。
- 准备耗尽时普通棋子回补，将和兵不回补。
- 将军加兵营步数及响应固定一步；全部阵营退出时终局结束（未完整核验全部特殊平局组合）。
