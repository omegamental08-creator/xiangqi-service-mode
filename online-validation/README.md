# 联机验证版

这是独立于现有单文件游戏的联机验证模块，用于验证本地网络房间大厅、席位与准备状态、房间发现和锁定、断线重连、服务器权威状态、命令提交与回合推进。当前规则集是最小验证规则，不代表最终游戏规则。

## 启动

在本目录安装依赖后运行：

```powershell
npm install
npm start
```

打开两个浏览器窗口访问 `http://127.0.0.1:8080`，分别创建或从开放房间列表加入。局域网内其他设备可通过运行服务器电脑的局域网 IP 和端口访问；服务默认监听所有网卡，设置 `HOST=127.0.0.1` 可限制为本机。玩家确认参与后由房主开始验证对局。短暂断线会保留席位 60 秒，浏览器刷新后使用同一客户端身份恢复。

## 目录

- `server.js`：HTTP 静态服务、WebSocket 网关和权威房间服务。
- `client.js`：浏览器验证客户端，后续 AI 可按同样协议实现控制器。
- `rulesets/classic-validation.js`：可替换规则集示例。
- `protocol.md`：消息和状态协议。

该模块暂不接入现有 `chess_service_final.html`；它仍使用独立的相邻一格示例规则集。完整兵营模式和不透明空战还需要把地图、布子、隐藏航线、附加回合和服务器权威结算接入本协议。
