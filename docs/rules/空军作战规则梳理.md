# 空军作战规则梳理

> 来源：[[象棋兵营模式完整规则]] §5.4、§5.5、§12.4、§13、§25、§27；图谱节点 [[09-空战]]、[[新玩法开发]]。

## 1. 版本定位

| 版本 | 空军状态 |
| --- | --- |
| 0.0 / 1.0 / 2.0 | 无空军体系 |
| 3.0 / 4.0 | 启用空战（防 / 直 / 战三件套）【正式】 |
| 3.0 / 4.0 扩展 | 新增轰炸机「轰」+ 信息不透明 + 逐格演算【草案】 |

空军的三个基础单位各司其职：**防**是地面防空阵地，**直**是能飞越的空中平台，**战**是唯一能主动打击的机型。

---

## 2. 棋子分类（§27.1）

空军棋子按「回合结束后是否占点」分成两条互不覆盖的轨：

| 类别 | 棋子 | 行为特征 | 结算轨道 |
| --- | --- | --- | --- |
| **模拟棋子** | 战、轰 | 航线确定后逐格模拟；结束回平台或坠机，**不常驻点位** | 空中格斗（飞行中「位置＋时间」相遇） |
| **占据棋子** | 防、直 | 本窗口行动完（各动一格）后**必然占住一个空点** | 同点全灭（回合末同点者全部消灭） |

要点：两轨并行、互不覆盖。「模拟棋子不受同点全灭限制」≠「模拟棋子没有碰撞规则」——它只是换到了空中格斗那条轨。

## 3. 单位明细

### 3.1 防空炮「防」【正式】

- 水性单位，**始终视为舰船**。
- 移动：上下左右 1 格。
- 不能吃掉任何棋子；不能执行普通攻击、接舷战、舰炮攻击。
- 以自身为中心形成 **3×3 点阵**的敌方战机**禁飞区**（进入即坠机）。
- 盟友的防不构成敌方禁飞区（即不拦自己人）。

### 3.2 直升机「直」【正式】

- 空中单位，沿横线或竖线移动。
- **可飞越任何棋子，但最终必须停在空点**；不能靠落在敌棋位置吃子。
- 上下左右**相邻四点**形成敌方战机的禁飞＋杀伤区，**不含斜对角**。
- 飞越能力**不**授予普通攻击 / 接舷 / 舰炮能力。

### 3.3 战机「战」【正式】

**起飞与航线**

- 从己方合格平台起飞；航线**最长 6 步**，不要求飞满。
- 起飞机坪不计第一步；每移动到相邻一点计 1 步，**不能斜飞、不能跳点**。
- 航程内可提前到达合法平台降落，也可返回起飞平台（降落仍须满足所属、激活、空载条件）。

**攻击**

- 可沿途攻击**敌方陆地单位**，**也允许攻击水面舰船**（不沿用「水性棋子一律免疫」）。
- 舰船被击毁时，船与乘员按**整船损失**处理（§10.7）。
- **不**按陆/海攻击规则击杀敌方空中单位（空对空走空中格斗，见 §27.8）。
- 进入敌方「防」的 3×3 或「直」的四邻 → **坠机**。

**降落与坠机**

- 必须降到己方**已激活且空载**的象 / 士 / 兵平台；**搭桥中的象不合格**。
- 无合法平台 → 终点坠机，战机进淘汰区。
- 坠机点若有棋子，**无论敌友**都受坠机冲撞；命中载员船按整船损失。
- 这是**落点冲撞**，不是周围 3×3 爆炸。

### 3.4 轰炸机「轰」【草案】

- 定位：专职对地，攻击性弱于战机，但具备战机一般特性（可被象搭载、需停机坪），归入模拟棋子。
- **逐格投弹**：每走一步就在该到达点投一枚炸弹，范围 **3×3**，沿航线形成线状轰炸带。
- 「试图」投弹：若该步被击落 / 被拦截，则该步不投，之后也不再投。
- **停机坪及其上停驻的棋子免疫炸弹**；停机坪附近的其它棋子照炸。
- **伤害二元、不叠加**：无血量，覆盖即清除，多枚覆盖算一次。
- **不分敌我**：己方目标照炸。
- **打不到空中的模拟棋子**（战 / 轰在模拟中在天上），只对地面 / 水面棋子生效。
- 可被防空火力击落，也可被战机按 §27.8 击落。

## 4. 生产（§12.4）【正式】

- 战机生产到**己方已激活、空载的象 / 士 / 兵平台**中，不直接出现在空地。
- 每平台只容 1 架战机，**不能同时搭载陆地乘员**。
- **搭桥中的象不能作为起降平台**。
- 兵的普通运输无需激活，但**作为战机平台仍须符合激活条件**。
- 准备区须有战机；生产属空军回合，**每回合最多 1 架**，新战机本回合已行动。

---

## 5. 回合与步数（§5.4、§5.5）【正式】

- 本回合**第一条命令**为生产战机或规划战机航线时，该回合成为**空军回合**。
- 空军回合**只能**生产战机或规划航线。
- 每回合最多生产 1 架。
- 所有战机航线与战机生产**共用一次空军步数划扣**。
- 广义单次划扣：同一棋子同回合通常只能执行一次移动 / 攻击 / 生产 / 装载 / 卸载 / 部署 / 航线行动；首次计费、同类后续可能免重复扣费，**以命令队列的步数提示为准**；步数不足不能入队。

## 6. 防空交互的未决点

- §13.3 末 + §25 Q5：**同一点既有可攻击目标、又处于防空区**时，防空检测与攻击的先后**尚待统一**。
- 明确禁止的默认假设：不能默认「先炸掉防空单位再免疫禁飞」。
- §10.2 提到「防空炮按其自身容量规则处理」，但「防」的容量数值**在本规则内未单独定义**，属表述待补齐项。

## 7. 不透明空战扩展（§27 · 联机限定 · 草案）

> 设计目的：制造不透明战场、放大猜疑链。**本地热座无法隐藏信息**，需另设计变通（物理遮挡、代客操作等），待定。

### 7.1 航线保密（§27.2）

- 规划中的航线对**其他所有方保密**，仅规划方可见（联机时服务器只推给规划方）。
- 可见性按阵营分：**敌方互不可见**；**友军（盟友）之间可见**彼此的空军行动。

### 7.2 30 秒附加回合（防空反应窗，§27.3）

触发：某方执行空军回合并**点击确认**时，追加 **30 秒**窗口。

- 窗口内**所有玩家**都能给自己的**空军棋子**（战 / 防 / 直 / 轰）下令；**其它棋子不能动**。
- 可以挪「防」「直」改变防空阵地，也可以为自己战机规划航线。
- 任何一方的空军移动，对其他方**都不透明**。
- **每颗空军子只能完成一个任务**，做完即锁定：防挪 1 格、直走 1 格、战 / 轰各一条航线；命令提交后不得微调（微调＝第二条命令）。
- 30 秒内不操作 = 该子原地不动（不代操作、不给默认动作）。
- 时间以**服务器时间**为准，迟到视为未操作（可留极短缓冲）。

### 7.3 强制确认（§27.4）

30 秒一到**强制给每个玩家点确认**；未确认者由系统代为确认，直接进入结算。

### 7.4 起飞前置条件（§27.5）

航线没排满 6 个航点，或没设好「一个停机坪到另一个停机坪」的路径点 → **这架飞机本回合不起飞**（防半截航线产生结算 bug）。

### 7.5 结算（§27.6）

- **防空阵地变更之后，战机仍按「首先开启空军回合的玩家」规划的航线移动**。
- 记录变更后的防空阵地**是否击落了战机**。
- 其他玩家的战机也依次模拟，与防空阵地演算，判定**摧毁目标**或**被击落**。

### 7.6 逐格同步演算（§27.7）

- 一格格来：先全体走第 1 格，再全体第 2 格……直到第 6 格。
- 提前回到停机坪的战机退出后续模拟。

### 7.7 空中格斗（§27.8）

| 情形 | 结果 |
| --- | --- |
| 同刻同点（同一次模拟刻到达同一点） | 相撞，**双方坠亡** |
| 先后抵达同一点 | **先到的那架**在「后到者踩点」的那一刻坠亡（视作被后方锁定） |
| 3~4 架依次经过同一交点 | **接力式连锁摧毁**：第 1 被第 2 吃、第 2 被第 3 吃…… |

- 以上**只决定谁坠亡，不改变任何航线**——航线在确认时刻即冻结。
- 优先级＝时间（模拟刻）；同一格永远只存在一个「活着的」印记。
- 实现方案：采用**方案二 · 飞行印记**（不预求交点，飞过留印记，后机踩上则前机坠亡）；理由是能顺带承接「轰」的逐格投弹逻辑。

### 7.8 占据棋子同点阵亡（§27.10）

- 回合结束后多枚**占据棋子**（防 / 直）位于同一点 → **全部消灭，不分敌我友**。
- 目的：根除多点重合 bug。友军能避免撞点，正是因为他们互相可见（§27.2）。

### 7.9 演算流程（§27.12）

1. 进入空军回合 → 规划航线（保密）
2. 点击确认 → 触发 30 秒附加回合
3. 30 秒内：各方向自己的空军子下令（每子一任务），重布防空、规划己方航线
4. 30 秒到 → 强制全员确认；未排满航线者不起飞
5. 锁定开局方航线 + 各方防空阵地 + 其他方航线
6. 逐格演算（第 1…6 格）：空中格斗、防空击落、轰炸、目标摧毁、坠机冲撞；已回坪者退出
7. 得出结算 → 进入后续回合

### 7.10 由既有规则推演出的结果（非独立规则，§27.11 摘要）

1. 接力式连锁摧毁（§27.8）
2. 空战优先级＝时间，同刻同点双亡（§27.8）
3. 炸弹伤害不叠加（§27.9）
4. **被防空火力击落的「轰」必然带走击杀它的那枚防 / 直**——死亡点紧邻防空子，遗弹 3×3 必覆盖之（几何必然）；若被战机击落则不一定
5. 「每子一任务」＝本窗口只接受一条有效命令
6. 30 秒不操作＝原地不动
7. 轰炸包含己方目标
8. 停机坪免疫及于其上停驻的棋子
9. 落地平台与坠机冲撞沿用 §13.3
10. 30 秒窗口以服务器时间为准
11. 模拟棋子不吃炸弹

## 9. 速查表

| 问题 | 答案 |
| --- | --- |
| 谁能打下战机？ | 敌方「防」3×3、「直」四邻；空中格斗另行处理 |
| 战机最多飞多远？ | 6 步，起飞机坪不计第一步 |
| 战机能否打船？ | 能，且整船损失 |
| 战机能否打敌机？ | 不按沿途攻击；走空中格斗（草案） |
| 落哪里？ | 己方已激活、空载的象 / 士 / 兵平台；搭桥象不行 |
| 没有平台怎么办？ | 终点坠机 + 落点冲撞（不分敌友） |
| 每回合造几架？ | 最多 1 架，且与航线共用一次空军步数 |
| 空军回合还能干什么？ | 只能生产战机或规划航线 |
| 「防」能攻击吗？ | 不能：无普通吃子、无接舷、无舰炮 |
| 「直」能攻击吗？ | 不能：只能飞到空点，靠禁飞区拦人 |
| 「轰」的炸弹会炸自己吗？ | 会，不分敌我；但停机坪及其上棋子免疫 |
