# 电脑模块

## 当前能力

- **正规AI**：只从游戏提供的合法动作清单中选择动作，支持移动、攻击、生产、兵营、激活/部署、自爆、装载/卸载、象搭桥和战机航线。
- **测试AI**：大部分时间执行合法动作，按设定概率提交越界、敌方棋子、未知命令等异常请求。异常必须由规则接口拒绝，不会直接改棋盘。
- **AI自对弈**：在游戏内打开“电脑”，点击“全部设为正规AI”即可。可随时暂停、改回真人或导出记录。
- **外部AI**：通过 HTTP JSON 接口选择动作；接口无响应时自动改用离线正规AI。
- **外部测试AI**：接入同一 HTTP 接口，并按异常尝试率注入规则探针，检查外部接入流程的拦截能力。

当前采用规则评分与有限候选搜索，不依赖网络，也不需要提前收集大量棋谱。规则仍在频繁变化时，这比直接训练神经网络更稳定。导出的自对弈数据可以逐步调整评分权重，规则稳定后再替换为强化学习模型。

当前版本重点覆盖常规棋子和已实现的游戏操作。多国外交仍由真人处理；搭桥象的特殊“拆桥攻击”只有在游戏主规则提供对应合法动作后，AI才会自动使用，避免电脑绕过规则自行结算。

## 游戏内使用

1. 正常进入一局游戏。
2. 点击顶部的“电脑”。
3. 将任意玩家改为“正规AI”“测试AI”或“外部AI”。
4. 点击“应用并运行”。轮到对应玩家时会自动下令并确认。
5. “保持暂停”会停止后续自动操作；重新打开面板并应用即可继续。

强度可选简单、普通、困难。简单模式会在多个合理动作中随机选择，困难模式降低随机度，稳定选择当前评分最高的动作。

在“本地多人房间”里也可以在开局前为 A-H 分配控制器。地图编辑和初始布子仍由房主完成；进入正式对局后，电脑席位自动接管。

## 外部AI接口

请求：

```http
POST /move
Content-Type: application/json
```

```json
{
  "protocol": "chess-barracks-ai/v1",
  "player": "A",
  "state": {},
  "legalActions": [{ "id": "move:piece-id:3:4", "type": "move" }],
  "requestId": "match-A-123"
}
```

响应只需返回合法动作的 `id`：

```json
{
  "action": { "id": "move:piece-id:3:4" }
}
```

游戏会重新核对该 `id` 是否仍在当前合法动作清单内。外部AI不能直接修改棋盘。

不依赖第三方包的本地示例：

```powershell
node ai/external_ai_example.js
```

然后在游戏的外部AI地址中填写 `http://127.0.0.1:8091/move`。

## 训练权重

在电脑窗口点击“导出日志”，完成多局后执行：

```powershell
node ai/tune_weights.js .\下载\chess-barracks-ai-第一局.json .\下载\chess-barracks-ai-第二局.json
```

脚本会生成 `ai/trained_weights.json`。在电脑窗口的“训练权重”处选择该文件并应用。训练器采用胜负结果进行轻量偏好更新，适合规则仍在迭代的阶段；它不是神经网络训练器。

## 浏览器接口

页面加载后提供 `window.ChessBarracksGameAPI`：

- `getState()`：获取只读局面。
- `listLegalActions(player)`：获取当前合法动作。
- `submitAction(action)`：验证并预演一条动作。
- `confirmTurn()`：确认当前命令队列。
- `clearTurn()`：清除命令并回滚。
- `endTurn()`：无命令时结束回合。
- `configureController(player, spec)`：设置某阵营控制器。
- `loadWeights(weights)`：加载训练权重。
- `pauseAI()` / `resumeAI()`：暂停或恢复。
- `getAILogs()`：读取运行日志。

## 运行时间与稳定性

“思考间隔”使用秒作为单位，范围为 `0.5` 到 `30` 秒，默认 `1` 秒。这个间隔用于控制每次 AI 思考和动作之间的可观察停顿，不会改变规则中的步数。

AI 回合带有独立的回合令牌和超时保护。打开设置面板、暂停、恢复或切换控制器时，旧计时器会被清理；控制器异常或外部接口超时会回退到离线正规 AI。运行日志最多保留最近 `2000` 条，训练样本最多保留最近 `240` 条。

测试长局时，建议把双方都设为“正规AI”，间隔设为 `0.5` 或 `1` 秒；出现停滞时打开“电脑”查看日志中的 `turn_start`、`action`、`rejected`、`controller_error` 和 `turn_end`。
